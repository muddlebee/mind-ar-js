# Asset credits

All graphics, textures, thumbnails, and accessory geometries added by this example are original procedural/vector artwork authored for the playground, licensed under the repository's MIT license. No photographs or personal camera frames are bundled.

| Effects | Source |
| --- | --- |
| Color-pop paint, carnival mask | Original alpha canvas textures, mapped through existing MindAR face UVs |
| Star cheeks, heart cheeks | Original canvas drawings and original SVG thumbnails |
| Round glasses, pixel shades | Original Three.js rings, planes, and box geometry |
| Crown, party hat | Original primitive geometry with authored placement |
| Hoops, drop earrings | Original primitive geometry with paired side-face anchors |

The depth-only facial occluder uses the existing MindAR face geometry and canonical landmark data. Existing bundled accessory models, unclear-license models, and SparkAR mask/head-occluder assets are not included or copied into `dist-try-on`.

Runtime credits: [MindAR](https://github.com/hiukim/mind-ar-js) (repository MIT license); [Three.js 0.136.0](https://github.com/mrdoob/three.js/tree/r136) (MIT); [MediaPipe Tasks Vision 0.10.9](https://www.npmjs.com/package/@mediapipe/tasks-vision/v/0.10.9) (Apache-2.0 package); existing MindAR OpenCV-based estimator. MediaPipe's externally downloaded face-landmarker model is a provider asset, not original playground artwork and not covered by the artwork's MIT statement. See the provider's model terms.

The app's About section links the shipped license notices. Repository MIT and Three.js MIT notices and the Apache-2.0 license are retained in `public/licenses.txt`; existing runtime copyright notices remain applicable.
